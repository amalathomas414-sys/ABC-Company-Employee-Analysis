# ABC-Company-Employee-Analysis
ABC Company Employee Data Analysis

1. Project Overview

This project analyzes employee data from ABC Company using Python. The objective is to preprocess the dataset, analyze employee distribution, study salary expenditure, identify the predominant age group, and visualize the relationship between age and salary.

2. Dataset Description

The dataset contains 458 employee records and 9 original columns. It includes information such as employee age, team, position, salary, height, and other employee details.

3. Tools and Libraries Used

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

4. Data Preprocessing

The dataset was loaded using Pandas and inspected to understand its structure, columns, data types, and missing values.

The Height column was replaced with random integer values between 150 and 180, as required by the assignment. A fixed random seed was used to make the generated values reproducible.

Missing values were examined before performing the analysis. Missing salary values were retained as missing values, so salary totals represent recorded salary data only.

5. Data Analysis Tasks

5.1 Employee Distribution Across Teams

The number of employees in each team was calculated using value counts. The percentage of employees in each team was calculated relative to the total number of employee records.

5.2 Employee Distribution by Position

Employees were grouped by their positions to identify the number of employees in each role.

5.3 Predominant Age Group

Employee ages were grouped into ranges to determine which age group had the highest number of employees.

5.4 Salary Expenditure by Team and Position

The total recorded salary was calculated separately for each team and position to identify the groups with the highest salary expenditure.

5.5 Correlation Between Age and Salary

The correlation between employee age and salary was calculated using records with both values available. A scatter plot was used to visualize the relationship.

6. Graphical Representations

The project includes visualizations to communicate the results of all five analysis tasks:

- Bar chart showing employee distribution across teams.
- Bar chart showing employee distribution by position.
- Bar chart showing the predominant age group.
- Bar charts showing salary expenditure by team and position.
- Scatter plot showing the relationship between age and salary.

7. Key Insights

The analysis identified the team with the highest employee count, the most common position, and the predominant age group. It also compared salary expenditure across teams and positions and examined the relationship between age and salary.

The exact findings are based on the results generated by running the Jupyter Notebook.

8. Limitations

- Height values are randomly generated replacements and do not represent actual employee heights.
- Missing salary values may affect the calculated salary totals.
- Correlation indicates association and does not establish causation.
- Findings depend on the completeness and quality of the available dataset.

9. Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, numerical calculations, and visualization. The analysis helps summarize employee demographics, team structure, position distribution, and salary patterns.
